## Convenciones

- Los textos entre corchetes con la palabra **COMPLETAR** — por ejemplo `[COMPLETAR: precio]` — son
  datos comerciales o de cada entidad que el proveedor llena antes de entregar el documento.
- Los nombres de botones y campos se escriben en **negrita**, tal como aparecen en pantalla.
- Los ejemplos usan datos ficticios.
